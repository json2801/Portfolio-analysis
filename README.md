Portfolio & Investment Data Analysis

📊 Project Overview

This project analyzes stock portfolio performance using historical market data and portfolio holdings. The analysis focuses on investment value, daily gains/losses, individual stock performance, and portfolio-level insights.

The project was developed as a portfolio analytics project to demonstrate practical skills in Excel, SQL, and Power BI.

🎯 Objectives

- Analyze portfolio holdings and investment values
- Calculate stock-level gain/loss and return
- Identify high- and low-performing investments
- Analyze daily portfolio performance
- Understand portfolio allocation
- Create an interactive Power BI dashboard for investment insights

🛠️ Technologies Used

- SQL / MySQL – Data querying and analysis
- Microsoft Excel – Data preparation, calculations, and validation
- Power BI – Interactive dashboard and data visualization


🔍 Analysis Performed

Portfolio Analysis

- Total investment value
- Current portfolio value
- Overall gain/loss
- Portfolio return percentage
- Individual stock performance

Stock Analysis

- Stock-wise returns
- Daily gain/loss
- Best-performing stocks
- Underperforming stocks
- Historical price trends

Allocation Analysis

- Portfolio distribution by stock
- Sector/category allocation
- Investment concentration

📈 Power BI Dashboard

The dashboard provides an interactive view of:

- Total Investment
- Current Portfolio Value
- Total Gain/Loss
- Portfolio Return %
- Stock Performance
- Portfolio Allocation
- Daily Performance

💡 Key Skills Demonstrated

- Data cleaning and validation
- SQL querying
- Excel-based analysis
- Financial data analysis
- KPI calculation
- Data visualization
